# Machine Learning Projects

This repository contains various Machine Learning projects and tools.

## Projects

### 📊 Machine Learning Notebooks
- **Loan Approval Prediction** - Loan approval prediction model
- **Mall Customer Clustering** - Customer segmentation analysis
- **Student Score Prediction** - Academic performance prediction
- **Walmart Sales Forecast** - Sales forecasting model

### 🚚 Truck Driver Expense Tracker
A comprehensive web-based application for truck drivers to track and manage their expenses on the road.

**[Open Truck Expense Tracker →](truck-expense-tracker/index.html)**

#### Features:
- Track expenses by category (Fuel, Tolls, Maintenance, Food, Lodging, Parking, Insurance, Other)
- Dashboard with total expenses and monthly summaries
- Filter and sort expenses
- Export data to CSV
- Responsive design for mobile and desktop
- Data persistence using browser localStorage

[View Full Documentation](truck-expense-tracker/README.md)

## Getting Started

### Machine Learning Notebooks
Open any `.ipynb` file in Jupyter Notebook or Google Colab to run the machine learning projects.

### Truck Expense Tracker
Simply open `truck-expense-tracker/index.html` in your web browser. No installation or setup required!

## Data

The `data/` directory contains datasets used in the machine learning projects.
